## 📖 项目简介

1909—1911 年，卢瑟福用 α 粒子轰击金箔，观察到"**绝大多数 α 粒子直线穿过，少数发生较大偏转，极少数被反弹回来**"，由此推翻了"葡萄干蛋糕"模型，提出核式原子结构模型。

本项目把这一经典实验搬进浏览器：

- **无需安装**、**无需联网**、**不依赖任何 AI 模型**——打开 HTML 文件即可运行；
- 学生可亲手调节「**粒子束数 / 金原子核数 / 能量 / 入射角**」，实时观察轨迹与统计；
- 在"调参数 → 看现象 → 得结论"的过程中，**自己撞见**那个震撼的结论：**原子内部 99.99% 都是空的**。

## ✨ 功能特性

### 1. `alpha_scattering.html` · α 粒子轰击金箔实验模拟

| 功能 | 说明 |
|---|---|
| **粒子束数** | **1 ~ 300 束自由输入**（默认 100 束），束流沿画布均匀分布 |
| **金原子核数** | 1 / 3 / 5 个，竖直排列模拟金箔切面，核与核之间留有"空隙" |
| **能量** | 1 ~ 10 MeV 滑块（能量越低，越容易被库仑力推开） |
| **入射角** | **−60° ~ +60°** 滑块，整个束场统一倾斜，橙色瞄准线随角度同步倾斜 |
| **正对束高亮** | 橙色束 = 正对某个金核，**只有它会被反弹**；其余束只能直穿或被偏转 |
| **实时统计** | 「直线穿过 / 偏转 / 反弹」三类结果实时计数 |
| **原子层级** | 金色金核（+79e）+ 最外层电子轨道（玻尔模型虚线圆，**相切排布**，模拟固态金箔的原子紧密堆积） |
| **署名胶囊** | 右下角"作者"标签，悬停平滑展开完整署名 |

**推荐体验**：`100 ~ 300 束 + 5 核 + 能量 5` → 绝大多数直线穿过、少数偏转、极少数反弹，正是卢瑟福当年观察到的分布。

### 2. `atomic_model.html` · 核式原子结构模型

- 前 8 号元素可选：氢 H / 氦 He / 锂 Li / 铍 Be / 硼 B / 碳 C / 氮 N / 氧 O
- 电子绕核运动动画，K 层 / L 层电子排布动态呈现
- 直观展示初中化学的排布规律：**K 层 ≤ 2，L 层 ≤ 8**

## ⚛️ 物理模型说明

程序采用的是一套**为初中课堂服务的简化物理模型**——追求"现象正确"，而非"数值精确"：

| 机制 | 实现方式 |
|---|---|
| **库仑斥力** | 逐核叠加 `F ∝ q₁q₂ / d²`，方向由核指向粒子；对距离做钳制 `d ≥ R_MIN`，等效于库仑势垒，同时消除 `d→0` 的数值发散 |
| **数值积分** | 每帧 **8 重子步长**采样，低速近核时轨迹依然平滑（消除"折角"） |
| **反弹判定** | 正对束的"沿入射方向速度分量"反向 → 计为**反弹**；非正对束按出射偏转角判定 |
| **直线判定** | 偏转角 < 10° 记作**直线穿过**（与视觉一致） |
| **电子轨道** | **纯视觉层**（浅色虚线圆），不参与物理计算——α 粒子只与金核发生库仑作用 |

> 📌 **一个容易被误解的物理点**：真实的 α 粒子（约 5 MeV）其实**碰不到金核**（金核库仑势垒约 20 MeV 以上），偏转 **100% 来自 1/r² 库仑斥力**。所谓"反弹"是被势垒推回，**不是几何碰撞**。

> 🧠 **一个可以带进课堂的问题**：把原子按真实比例放大到足球场那么大，金核只有一粒米大小。那 α 粒子要想"正对"金核，概率有多低？——这就是"极少数被反弹"的由来。

## 🎓 教学设计

`教学设计.md` 提供一份可直接使用的 **45 分钟课堂简案**：

| 环节 | 时间 | 核心内容 |
|---|---|---|
| 导入 | 5′ | 从"原子内部是什么样"引出**建模**思想 |
| α 粒子散射模拟 | 20′ | 调参观察轨迹 → 统计三类比例 → 归纳三条结论 |
| 核式原子结构模型 | 15′ | 观察前 8 号元素 → 总结电子排布规律 |
| 小结与拓展 | 5′ | 科学探究方法：**提出问题 → 建立模型 → 编程实现 → 验证结论** |

由实验现象得出的三条结论：

```
大多数直线穿过  →  原子内部十分空旷
少数发生偏转    →  原子核带正电
极少数被反弹    →  原子核体积小、质量大
```
