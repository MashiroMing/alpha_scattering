## 📖 项目简介

**一个模型是怎么被下一个证据推翻的？** 本项目把这条化学史线索做成了六个可以在课堂上直接操作的网页。

1909—1911 年，卢瑟福用 α 粒子轰击金箔，观察到"**绝大多数 α 粒子直线穿过，少数发生较大偏转，极少数被反弹回来**"，由此推翻了"葡萄干蛋糕"模型，提出核式原子结构模型。

但学生在教材上看到的往往只是"卢瑟福得出了核式结构"这个**结果**——看不到他为什么要轰金箔、也看不到"布丁模型到底错在哪"。所以本项目往前补了一环：

- **`cathode_ray.html`** —— 阴极射线在电场中偏向正极 → 学生自己推出"射线带负电、原子内有更小的粒子"，回答"**凭什么说原子能再分**"；
- **`electron_in_field.html`** —— 把阴极射线页的定性现象**升级成高中定量探究**：给出真实电压、板长、板距、磁感应强度与屏距，面板直接算出 `v`、`E`、`a`、`y₁`、`tanθ`、`R`、`T` 并列出公式代入过程，还能一键"汤姆逊配平"反推荷质比；
- **`alpha_scattering.html`** —— 除了核式模型，还能一键切到**布丁模型**做对照：同样的束数、能量、入射角，布丁模型下**一束都不会被弹回来** → 与实验现象矛盾 → **布丁模型被推翻**；
- **`atomic_model.html`** —— 把金原子"点开"，看到里面的 **79 个质子 + 118 个中子 + 79 个电子分层排布**；
- **`bohr_model_3d.html`** —— 同一套分层模型搬进**三维空间**（各层轨道平面互不重合），并把玻尔真正解决的问题补上：**电子从高能级掉到低能级会放出一个光子**，光子的能量正好等于两能级之差 → 计算出 656 nm 的 Hα，与氢光谱里那条**红色亮线**对上；
- **`index.html`** —— 五段化学史时间轴，作为课堂第一屏，一眼看到整条线索。

共同特点：

- **无需安装**、**无需联网**、**不依赖任何 AI 模型**——打开 HTML 文件即可运行（六页外部引用实测均为 0 处）；
- 学生可亲手调节参数，实时观察现象与统计；
- 在"调参数 → 看现象 → 得结论"的过程中，**自己撞见**结论，而不是被告知结论。

### 3. `alpha_scattering.html` · α 粒子轰击金箔实验模拟（主程序）

画布 **1200 × 900**，Canvas 2D 实时渲染；左画布 + 右栏（控件 / 统计 / 可折叠「实验说明」），1080p 投影一屏看全（实测内容总高 892px ≤ 929px）。

| 功能 | 说明 |
|---|---|
| **粒子束数** | **1 ~ 300 束自由输入**（默认 100 束），束流沿画布竖直均匀铺展 |
| **金原子核数** | **1 ~ 30 自由输入**（数字框，右侧实时显示「N 列 · M 行」）。列数自动分档：**1~10 单列 / 11~20 两列 / 21~30 三列**，默认 **27 = 3 列 × 9 行**。多列是金箔的**截面**：沿入射方向排几层，粒子会连续穿过几层原子；竖直多行，束场里每个落点周围都有邻居 |
| **能量** | 1 ~ 10 MeV 滑块（默认 5）。能量越低、粒子越慢，在核附近停留越久 → **偏转与反弹都明显增多**；能量越高，只有离核极近的少数才发生大角度偏转 |
| **入射角** | **−60° ~ +60°** 滑块，整个束场统一倾斜；偏转判据以入射方向为基准，斜射不会被误判 |
| **反弹怎么来的** | **算出来的，不是安排的**。旧版把每个核"正对"的那一条束吸附到穿过核心的直线上并强行掉头（橙色瞄准线）；v7.0 删掉了这套特判与库仑力上限，27 个核各自施加 1/r² 斥力，**头对头的粒子被自己"刹住并退回"**。橙色现在表示"飞出去时夹角 ≥ 90°"，是**结果**而不是标签 |
| **实时统计** | 「直线穿过 / 偏转 / 反弹」三类实时计数 + **百分比** + **累计样本数**。每次发射的落点都会重新抽样，所以多打几次百分比才会稳定 —— 这本身就是"为什么要大量重复"的演示 |
| **电子轨道** | 金色金核（+79e）+ 最外层电子轨道（玻尔模型虚线圆）。轨道半径 = 阵列间距 ÷ 2 → **相邻原子的轨道两向相切**，拼成一整片"密不透风的墙"，而 α 粒子照样穿过去 |
| **金箔层（教学动线开关）** | 打开页面默认盖着一片**金色薄层**（宽度 = 原子阵列外轮廓，层数越多越厚）。点「🔍 撤掉金箔」→ 金箔淡出（≈0.6s）、27 个金核与相切的电子轨道淡入；按钮随即变成「🟡 铺回金箔」，可反复对照。「重置」也会回到金箔态。**物理零改动** —— 金箔只遮挡视觉 |

**两种模型的对照实测**（300 束 × 3 批 = 900 个粒子 / 27 核 / 能量 5 MeV / 入射角 0°）：

| 原子模型 | 直线穿过 | 偏转 | 反弹 | 飞行全程最大偏转角 |
|---|---|---|---|---|
| **核式模型** | 700（77.8%） | 177（19.7%） | **23（2.6%）** | **167.8°** |
| **布丁模型** | **900（100%）** | **0** | **0** | 5.9°（轻轻推一下，远远够不到反弹） |

> 布丁模型下 **一束都不会被弹回来**，而教材明确写着"极少数 α 粒子被反弹回来" —— **矛盾 → 布丁模型错了**。这正是卢瑟福推翻它的逻辑。注意这条对照现在是**物理结论**：同一套 1/r² 公式、同一套判据，只有"正电荷怎么分布"不同，没有任何 `if (布丁) 不许反弹` 的代码。

**能量档位实测**（300 束 / 27 核，偏转 + 反弹个数）：E = 1 MeV → **205 个**；5 MeV → **63 个**；10 MeV → **54 个**。低能更容易被推开，方向与教材一致。

> ⚠️ **1 MeV 是极端档**：约 22% 的粒子被反弹回去。它适合演示"低能 → 更容易被推开"这个**方向**，不适合代表教材里"极少数被反弹"的**比例** —— 那个比例对应默认的 5 MeV（约 2%）。

**课堂动线（先现象、后本质）**：打开页面 → **默认就是「金箔铺着 + 27 个金核」**，此时学生看到的只有三种现象，看不到任何核 → 点「🔍 撤掉金箔」，27 个金核与相切的电子轨道虚线圆一起现身 → 再发射一次做对比 → 最后把「原子模型」切到**布丁模型**再发一次，让学生看到"一束都不偏、更不反弹"，自己得出"这个模型站不住"的结论。

**推荐体验**：`300 束 + 27 核 + 能量 5` → 绝大多数直线穿过、少数偏转、极少数反弹，正是卢瑟福当年观察到的分布。**然后连点几次「发射」**，看百分比逐步稳定 —— 单次 100 束里反弹可能只有 1~2 个，样本堆到上千才可靠。
**想看到明显偏转**：把能量调到 1 ~ 2 MeV。
**性能**：物理内核（27 核 × 300 束 × 8~64 子步）实测约 **1.3 ms/帧**（Node 单线程同构积分器，占 60fps 预算 16.7 ms 的 8%）；绘制侧沿用旧版的分级瘦身（≥ 50 束密集模式、≥ 200 束极密模式），300 束仍保持流畅。

> ⚠️ **关于"比例真不真"**：真实 5 MeV α 对 0.4 μm 金箔，>90° 反弹约 **1/26000**、>10° 偏转约 **0.5%**。本页是 **2D 截面**（概率对碰撞参数是线性的，真实三维是平方的），不可能复刻这个量级 —— 所以比例是**放大过的**（本页 5 MeV 约 2% vs 真实 0.004%）。页面的价值在**因果与趋势**（核多 → 偏转多；能量低 → 偏转多；布丁 → 零反弹），不在数值复刻。

### 5. `electron_in_field.html` · 带电粒子在场中的运动（高中定量探究）

画布 **1200 × 900** + 右栏 540px（控件 / 现象解读卡 / 四段数据公式面板 ①加速 ②电偏转 ③磁偏转 ④正交场 / 可折叠「怎么用 · 公式速查」），1080p 投影一屏看全（实测内容总高 892px ≤ 929px）。

**一套装置跑四种工况**，靠 `U`、`B` 是否为 0 自动切换，不用换页：

| 工况 | 画面 | 面板给出的量 |
|---|---|---|
| 只加 `U₀` | 匀速直线 | `v = √(2qU₀/m)` —— 默认 `2.652×10⁷ m/s` |
| 只加 `U` | 类平抛 | `E`、`a`、`t₁`、`y₁`、`tanθ`、屏上总偏移 `Y` |
| 只加 `B` | 匀速圆周 | `R`、`T`、圆心 `O`、圆心角 `φ`、偏向角 `β` |
| `U`、`B` 同加 | 正交场 | 速度选择器条件 `v = E/B`、反推 `q/m` |

| 功能 | 说明 |
|---|---|
| **装置串联** | 左→右：阴极 + **双孔阳极**（`U₀` 加速）→ **平行板**（`U` 偏转）→ **圆形有界磁场区**（`B`）→ **荧光屏**。四段在同一条中轴上，粒子一路走到底 |
| **真实几何口径** | 比例尺 `1 cm = 40 px`；极板长 `L = 7.50 cm`、间距 `d = 2.00 cm`、磁场区半径 `4.00 cm` —— **面板里的数字可以直接拿去出题** |
| **屏距 D 可调（2.0 – 12.5 cm）** | 拖动滑杆时荧光屏**真的在画布上左右移动**。`y₁`、`tanθ` 不随 `D` 变，`Y = y₁ + D·tanθ` 对 `D` 是一次函数（实测斜率 0.1872 = `tanθ`，D 从 2 → 12.5 cm 使 `Y` 从 1.077 → 3.043 cm）——这正是示波管要长脖子的原因 |
| **屏上直接读出偏移量** | 屏左侧一条**双箭头尺寸线**从中轴量到光斑，旁挂数值胶囊 `Y = 3.04 cm ↑ 向上`（无偏转时显示「Y = 0 · 光斑正中」）；与右栏解析值并列可对照 |
| **参数可手填精调** | 每个参数都是「**滑杆粗调 + 数字框精调**」。数字框支持任意精度（如 `U₀ = 1837.5 V`、`B = 0.3769 mT`），填的值既不受滑杆 step 限制、也不会被量程夹掉（滑杆量程自动扩展容纳）；只对物理硬限封顶：`U₀ ∈ [1, 20000] V`、`U ∈ ±50000 V`、`B = ±(基准量程×5)`、`D ∈ [0.5, 12.8] cm` |
| **粒子四选** | **电子 / 质子 / α 粒子 / 自定义**（可手填电荷量 `q`（以 e 为单位）与质量 `m`（以 u 为单位）），同场对比不同 `q`、`m` 的偏转差异 |
| **B 量程随粒子自动切换** | 电子 ±20 mT / 质子 ±500 / α ±700 / 自定义 ±300 —— 单一量程无法同时服务电子与质子（同样可见弧度差 40 倍以上） |
| **辅助显示三开关** | 「速度分解」（出板处画 `v∥`、`v⊥` 与合速度）、「反向延长线」（虚线回中轴，落点必为极板中点）、「磁场圆心 / 半径」（画 `R` 的圆与圆心 `O`） |
| **⚖ 汤姆逊配平** | 一键自动扫出使净偏转为零的 `B`。电子 + `U₀=2000 V` + `U=200 V` → `B = 0.3769 mT`，**反推 `q/m` 与理论值误差 0.078%**，出板斜率与屏上偏移均为 0（光斑回到正中） |
| **正交场 = 速度选择器** | 交叉场工况下磁场区**与极板同区间**（不是延伸到屏前），两个场作用在同一段区域、**出板即离场** → 配平后沿中轴直线飞到屏正中，正是教科书里速度选择器的样子 |
| **换粒子看差异** | 换成质子 / α：`y₁`、`tanθ` **大小完全不变、符号相反**（公式里 `q`、`m` 被 `U₀` 约掉，经典考点），但磁场里的 `R`、`T` 差了几千倍 |
| **预设按钮** | ⚡ 类平抛 / 🌀 磁场圆周 / ⚖ 汤姆逊配平，一键切到典型工况；另有 ⏸ 暂停 / ▶ 发射 / 🔄 重置 |
| **流动的粒子** | 沿轨迹流动的亮点；轨迹由**真实数值积分**逐步算出，不是画出来的示意曲线 |
| **返回探索史** | 左上角固定定位的「← 原子探索史」胶囊，回到 `index.html`（不占布局高度） |

**四种工况的实测数据**（电子 / `U₀ = 2000 V`）：

| 工况 | 参数 | 解析值 | 数值积分 |
|---|---|---|---|
| 只加速 | `U₀ = 2000 V` | `v = 2.652×10⁷ m/s` | 光斑落在中轴（偏差 0） |
| 电偏转 | `U = 200 V` | `y₁ = 0.703 cm`、`tanθ = 0.1875` | `y₁ = 0.702 cm`、`tanθ = 0.1872` |
| 磁偏转 | `B = 5 mT ⊗` | `R = 3.02 cm`、`T = 7.145 ns` | 电子向下弯，与电场方向相反 |
| 正交场配平 | `B = 0.3769 mT` | `q/m = 1.76×10¹¹ C/kg` | 误差 **0.078%**，出板斜率 0、屏上偏移 **0 cm** |

> 🎯 **课堂动线**：① 只加 `U` → 讲类平抛怎么"拆成两个方向"来算，再勾上「反向延长线」坐实"反向延长必过极板中点"这条几何结论；② 撤掉 `U` 换成 `B` → 讲圆心怎么找、`T` 与速率**无关**；③ `U`、`B` 同时上 → 点「汤姆逊配平」，看粒子不偏不倚走直线、光斑回到正中，反推 `q/m`。

> 📎 这一页与 `cathode_ray.html` 同源：**1897 年汤姆逊就是用这套"电场偏转 = 磁场偏转"的方法测出电子荷质比的**——定性页回答"是不是粒子"，定量页回答"这粒子有多重、带多少电"。

### 6. `bohr_model_3d.html` · 玻尔原子模型（三维电子运动 + 能级跃迁）

画布 **1000 × 675** + 右上 780px「元素周期表 / 能级跃迁与光谱 / 信息与说明」三张卡片，画布下方一条视图控制条（实测内容总高 918px ≤ 929px，1080p 投影一屏看全）。

**为什么还要做一页三维的？** `atomic_model.html` 把电子层画在**一个平面**上，学生会以为所有电子都挤在同一个盘面里绕核转。真实的电子层是在**三维空间**里、各自占据**不同取向的轨道平面**。这一页把这件事画出来，顺带补上玻尔模型真正的贡献——**跃迁**。

| 功能 | 说明 |
|---|---|
| **三维轨道** | 每一层电子各自在一个**倾斜的轨道平面**上运动（各层法向量两两不平行，探针实测 `\|cos\| ≤ 0.985`）；用鼠标拖动可任意旋转视角，默认缓慢自转 |
| **真三维数学** | 旋转矩阵 + 透视投影 + 按深度排序逐段绘制（画家算法）：远处的轨道线与电子更细、更暗，近处的更亮 —— 深度线索不是靠颜色硬贴的。**零依赖**：只用 Canvas 2D 光栅化，没有引入 three.js / WebGL |
| **轨道半径** | `r ∝ n^1.5`，最外层归一化到显示半径（真实玻尔模型为 `n²`，压缩后才装得下 1~6 层，页面内已注明） |
| **空能级** | 氢原子画出 **n = 1~6 全部六个能级**，未被电子占据的画成**虚线圆** —— 为跃迁演示留好落点 |
| **能级跃迁** | 点按钮 → 电子先被**激发**到高能级 → **下落** → 差值以**一个光子**放出（画布上能看到一条正弦波形的光子飞出去）→ 右侧能级图上打出 ΔE 箭头、光谱条上对应的那条线**点亮** |
| **氢原子光谱** | 能级图 `Eₙ = −13.6/n² eV` + 发射光谱条（350–800 nm，紫外/红外区压暗）。**巴耳末系四条 Hα 656 / Hβ 486 / Hγ 434 / Hδ 410 nm 全部落在可见光区**，与氢放电管肉眼看到的四条亮线一一对应；另有莱曼系 2→1（紫外 122 nm）与帕邢系 4→3（红外 1876 nm）作对照 |
| **可对账的数值** | 六条谱线的波长与教科书值**误差 ≤ 0.3 nm**（`λ = hc/ΔE`，取 `hc = 1240 eV·nm`），探针逐条断言 |
| **连放演示** | 「▶ 连放巴耳末四线」依次演示 3→2、4→2、5→2、6→2，四条线逐条点亮 —— 正好复刻"氢光谱那四条亮线是怎么来的" |
| **教学诚实** | 玻尔公式只对**氢（及类氢离子）**严格成立：切到其它元素时，跃迁按钮**自动禁用**、能级图给出遮罩说明，只保留三维分层结构（不编造多电子原子的能级） |
| **元素周期表** | 与 `atomic_model.html` 同款：7 周期 × 18 族骨架，37 个可点、其余灰显；**选中元素整行整列高亮** |
| **署名 / 返回** | 右下角「作者」胶囊 + 左上角「← 原子探索史」，均为固定定位、不占布局高度 |

> 🎯 **课堂动线**：① 先看三维：拖动旋转，问"两层电子的轨道在不在同一个平面上" → ② 切到氩（3 层 18 电子）看层数与电子数 → ③ 切回**氢**，点「3→2」：电子先被激发、再掉下来、飞出一个光子，光谱条上 656 nm 那条**红线亮起** → ④ 点「连放巴耳末四线」：四条线依次点亮，问"这几条线为什么是分开的" → ⑤ 结论：**轨道（定态）是分立的，所以发光也是分立的** —— 这就是 1913 年玻尔解释线状光谱的思路。
>
> 📎 与 `atomic_model.html` 的分工：那一页回答"**电子怎么分层排布**"（静态、二维、讲周期律），这一页回答"**分层为什么能解释发光**"（动态、三维、讲跃迁）。

### 📱 在安卓平板 / 手机上打开（请用单文件版）

Windows / macOS 上双击 `index.html` 一切正常，但把整个文件夹拷到 Android 设备后，从「文件管理」里点开 HTML 常常只有**一个**页面能进，其余报：

```
网页无法打开，位于 file:///storage/emulated/0/Android/data/<浏览器包名>/files/opened/cathode_ray.html
net::ERR_FILE_NOT_FOUND
```

这不是页面写错了。从文件管理点开 HTML 时，浏览器拿到的通常是 `content://` 链接，它的处理方式是**把被点的那一个文件复制进自己的私有目录**（如 `.../files/opened/`）再以 `file://` 加载。于是页面里的相对链接 `cathode_ray.html` 被解析成「那个私有目录里的同名文件」—— 那里当然没有，只能 404。之前能进的那一个页面，只是恰好也在暂存目录里（单独打开过一次）。

**解法：用单文件版。**

| 文件 | 说明 |
|---|---|
| `atom_sim_single.html` | 六页全部内联，约 **513 KB**，**拷到哪里都能单独打开**，六页之间照常互相跳转 |

- 六页各自跑在 iframe 里（CSS / id / 全局变量天然隔离，互不污染），页间跳转由外层拦截后切换；
- 入口按钮、「← 原子探索史」、α 页点金核开模型页都能用；地址栏 `#bohr` / `#model` / `#alpha` 也可直达；
- 平板布局与逐页单独打开**完全一致**（媒体查询按 iframe 视口算）；
- ⚠️ **改过任何一页之后必须重新生成**，否则单文件版还是旧的：`python tools/build_single.py`。
- 📛 **文件名故意用纯英文**（历史版本曾叫「原子结构模拟_单文件版.html」）：中文名在 GitHub 网页上传、raw 下载、以及 Contents API 拼 URL 时都要 percent-encode，容易出问题（本项目就踩过 —— 远端明明有文件，核验脚本却报取不到，真因是 URL 里直接放了中文）。改成 ASCII 名后整条链路都不用再管编码，拷到平板上也不会出现文件名乱码。

> 💡 课堂投影建议使用 Chrome / Edge / Firefox 等现代浏览器**全屏（F11）**展示。

## ⚛️ 物理模型说明

五个画布页里，阴极射线 / α 散射两页使用**为中学课堂服务的简化物理模型**——追求"现象正确"，而非"数值精确"。`electron_in_field.html` 是**高中定量页**，给的是真实物理量 + 逐帧数值积分，可以与解析公式**逐项对账**（见下节 ④）。`atomic_model.html` 与 `bohr_model_3d.html` 是**结构示意页**：元素数据取真实核素，但轨道半径、转速、轨道平面取向都经过压缩或错开，只为把"分层"与"跃迁"看清楚（见下节 ⑤ 与「已知限制」）。

### ① α 散射页 · 核式模型

| 机制 | 实现方式 |
|---|---|
| **核阵列** | 核数 **1 ~ 30 自由输入**，列数自动分档：**1~10 → 单列 / 11~20 → 两列 / 21~30 → 三列**。布点是**三角（六方）网** —— 金的 (111) 最密堆积面：同列相邻核距 = 最近邻 `nn`，相邻列沿 y **错开 nn/2**，列距 = `nn·√3/2`（于是斜向邻居的距离也正好等于 `nn`）。含错位的总跨度固定 800px，`nn` 按核数自适应（单列且核很少时最多 150px，27 核时 **94.1px**）；核数不能整除列数时多出来的给左边的列，整片阵列按包围盒竖直居中。默认 **27 = 3 列 × 9 行** |
| **电子轨道半径** | = **nn/2** → 每个圆恰好与 6 个最近邻相切、彼此不重叠（真六方密排的判据）。27 核时 **47.1px**，30 核（nn 84.2）**42.1px**，5 核单列 **75px** |
| **金箔半宽** | = (列数 − 1)·列距/2 + 轨道半径：27 核 **128.6px**、20 核 **78.6px**、30 核 **115px**、单列 75px（标签位置至少离中心 120px，不压轨道） |
| **库仑斥力** | 逐核**叠加** `F = k·q₁q₂ / d²`（`k = 0.06`、`q₁ = 2`、`q₂ = 79`），方向由核指向粒子。**纯 1/r²，不给力设上限、不给距离设下限** |
| **近距离怎么不炸** | **自适应子步**：每帧先探测粒子到最近核的距离，`d < 45px` 时子步数由 8 提到 **64**（`dt` 缩到 1/8），远离时退回 8。`dt` 变小 → 单步位移与力的变化都足够小，`d` 很小时积分依然稳定，**不需要用钳制去"救"数值** |
| **能量响应** | 能量**只通过速度**影响偏转（速度越快 → 在核附近停留越短 → 冲量越小）。力公式里**不含能量项** —— 所以能量不会被"力里除一次、速度里再除一次"地双重计入 |
| **数值积分** | 8 重子步（近核 64 重）。实测把子步加到 8 / 32 / 96 / 384，`b → θ` 曲线**完全重合** —— 说明远场 8 重足够、64 重只在近核补位，结果不是"子步调出来的" |
| **反弹判定** | **出射方向与入射方向的夹角 ≥ 90°** → 反弹；**≥ 10°** → 偏转；其余 → 直线穿过。三分类只有**一个判据入口**，逐粒子独立算，**没有任何"安排好的"特判** |
| **电子轨道** | **纯视觉层**（浅色虚线圆，半径 = 最近邻间距的一半 = **47.1px**，与 6 个最近邻相切），不参与物理计算 |
| **采样口径** | 每次发射把整片束场竖直平移一个**随机相位** `(r − 0.5) × 100px`（mulberry32 + 递增种子）。物理上等价于"金箔不动、落点随机"，所以**连点几次得到的百分比才能累加成统计** |

#### 阵列为什么是三角网（金 = 面心立方最密堆积）

金**既不是简单立方，也不是体心立方**：

| 堆积方式 | 配位数 | 空间利用率 | 代表金属 |
|---|---|---|---|
| 简单立方 | 6 | 52.4% | 只有钋（Po） |
| 体心立方（A2） | 8 | 68.0% | Na、K、α-Fe、Cr、W |
| 六方最密（A3） | 12 | 74.05% | Mg、Zn、Ti |
| **面心立方最密（A1）** | **12** | **74.05%** | **Cu、Ag、Au**、Al |

金：a = 4.078 Å、每个晶胞 4 个原子、最近邻 2.884 Å（= 2 × 金属半径 144 pm）。

本页只有 2D 截面，取**最密的 (111) 面**：该面是**三角（六方）点阵**，面内每个原子的 6 个邻居都与它相切（完整晶体 12 个近邻，一半在这一层）。由此得三条硬约束：

- **不能**摆成"列距 = 行距"的方形格子 —— 那是简单立方的观感；而且面密度比最密面低 **13.4%**（方形 `1/d²` vs 三角 `2/(√3·d²)`）。
- 相邻列必须**错开半格**（`nn/2`），斜向邻居距离才等于 `nn`；不错开的话斜向距离是 `√2·nn`，轨道就切不上了。
- 列距 = `nn·√3/2`（三角网的"行高"），不是 `nn`。

探针据此用**结构判据**而不是硬编码像素：`maxCoord === 6`（每个核恰好 6 个最近邻）、`2 × 轨道半径 === nn`、横向跨度 `=== nn·√3`、多列时相邻列起始 y 相差 `nn/2`。

> ⚠️ 一个仍然存在的简化：真实金箔是三维晶体，每个原子 12 个近邻；这里只画一层 (111) 面（6 个近邻）。另外 `nn`（94.1px）与 `b₉₀`（约 1.5px）的比例是**放大过的**，见下面的"尺度不真实"说明。

#### 为什么"反弹"是算出来的，不是安排的

旧版给每个核配一条**正对的束**（把束吸附到穿过核心的入射线上），再判"沿入射方向的速度分量是否为负"——于是 `反弹数 ≡ 核数`，加束数只是让这个比例"看起来更像极少数"。**现在这条路被彻底删掉了**：束的位置完全由随机相位决定，粒子朝哪儿飞，只取决于它穿过的 27 个库仑场怎么叠加。

单个金核的偏转角与瞄准距离 `b`（k = 0.06、5 MeV）：

| b（px） | 0 | 0.5 | 1 | 2 | 3 | 5 | 8 | 12 | 20 | 40 |
|---|---|---|---|---|---|---|---|---|---|---|
| 出射偏转 | **180°** | 86° | 50° | 26° | 18° | 11° | 7° | 4° | 3° | 1° |

**要偏过 90°，必须擦到离核心 ~0.4px 以内**。300 束均匀撒在 94px 的最近邻间距上，落在这么个窗口里的概率本就极低 —— 这正是"极少数被反弹"的来源，也解释了为什么**多核比单核更接近教材**：

| 核数 | 列 × 行 | 最近邻 nn | 直线穿过 | 偏转 | 反弹 |
|---|---|---|---|---|---|
| 1 | 1 × 1 | — | 98.8% | 1.1% | 0.2% |
| 5 | 1 × 5 | 150.0 | 93.5% | 6.0% | 0.5% |
| 10 | 1 × 10 | 88.9 | 88.3% | 10.8% | 1.0% |
| 11 | 2 × 6 | 145.5 | 86.2% | 12.6% | 1.3% |
| 15 | 2 × 8 | 106.7 | 80.4% | 17.5% | 2.1% |
| 20 | 2 × 10 | 84.2 | 75.8% | 22.0% | 2.3% |
| 21 | 3 × 7 | 123.1 | 82.5% | 15.4% | 2.1% |
| 24 | 3 × 8 | 106.7 | 79.8% | 18.3% | 2.0% |
| **27** | **3 × 9** | **94.1** | **77.2%** | **20.8%** | **2.1%** |
| 30 | 3 × 10 | 84.2 | 75.3% | 21.5% | 3.2% |

两条路都能通往 90°：**① 某个核擦得极近**（单次大偏转）；**② 连续擦过几个核，小偏转叠加起来**（旧版完全做不到这件事，因为每条束只认一个核）。核数越多、路径越"曲折"，第 ② 条路才越有戏。

注意 **20 核（nn 84.2、两列）反而比 27 核（nn 94.1、三列）偏转更多** —— 决定偏转率的是**面密度（最近邻间距）**，不是核数本身。"多一列、多一次散射"抵不过间距缩小 10% 带来的近距碰撞；`nn` 是被"总跨度 800px ÷ 行数"反推出来的，所以核数与密度不是单调对应。

#### 核数 1~30 与"列数自动分档"

核数不再是 1 / 5 / 27 三档，而是 **1 ~ 30 连续可调**；列数由核数自动决定 —— **1~10 单列、11~20 两列、21~30 三列**，每列的核在竖直方向等距铺开（总跨度 800px，行距按核数自适应），核数不能整除列数时多出来的给左边的列、短的那列仍以画布中线为心居中。

分档的依据是**列数 = 粒子要连续穿过几层原子**：单列只能"擦一次"，三列才有小偏转累积的机会。所以「核数 → 列数」不是凑数，而是把"样本密度"和"多次散射"这两件事同时调上去。

实测（E = 5 MeV、300 束 × 4 批 = 1200 个粒子/档，同一套判据）：

|---|---|---|---|---|---|
| 1 | 1 × 1 | — | 98.8% | 1.1% | 0.2% |
| 5 | 1 × 5 | 150.0 | 93.5% | 6.0% | 0.5% |
| 10 | 1 × 10 | 88.9 | 88.3% | 10.8% | 1.0% |
| 11 | 2 × 6 | 145.5 | 86.2% | 12.6% | 1.3% |
| 15 | 2 × 8 | 106.7 | 80.4% | 17.5% | 2.1% |
| 20 | 2 × 10 | 84.2 | 75.8% | 22.0% | 2.3% |
| 21 | 3 × 7 | 123.1 | 82.5% | 15.4% | 2.1% |
| 24 | 3 × 8 | 106.7 | 79.8% | 18.3% | 2.0% |
| **27** | **3 × 9** | **94.1** | **77.2%** | **20.8%** | **2.1%** |
| 30 | 3 × 10 | 84.2 | 75.3% | 21.5% | 3.2% |

> 顺带解释为什么默认选 **27 核**：30 核（nn 84.2、3 × 10）的反弹率 3.2% 只比 27 核的 2.1% 高一个千分点，在 1200 样本上已接近噪声；但 27 核的画面更疏、物理开销更小，读起来也更清楚。

#### 轨迹上那些"折角"是怎么回事

有人会注意到：某几条 α 轨迹看起来不是平滑曲线，而是在核附近**突然拐一下**。这**不是插值或渲染的问题**，量测结果如下（27 核 / 120 束，直接读页面里的 `trail` 数组）：

| 指标 | 实测 |
|---|---|
| 相邻轨迹点间距 | 中位数 **0.534px**、p99 **0.546px**、最大 **0.549px** —— 全程等距，**没有任何断点**（断点会让线变成"长直弦"） |
| 相邻两段的方向差 | 最大 **3.88°**（在离核最近的 1~2 个点上），超过 1° 的只占 **0.029%**，超过 5° 的 **0 个** |
| 与超高精度积分（512 / 4096 子步）的路径偏离 | b ≥ 1px 时 **0.03 ~ 0.3px**；只有 b ≈ 0.5px 的头对头情形到 3.7px |

也就是说：**画出来的折线数据上是平滑的**，曲率半径最小约 8px。真正的折角来自物理本身 —— 偏转集中发生在最近距离 `b` 附近（`tan(θ/2) ∝ 1/b`），当 `b` 只有 1~4px 时，整段几十度的转折就被压缩在核边那几个像素里，看上去就是"一折到底"。同理，27 核画面里多条轨迹互相交叉，也会被眼睛读成折线。

> 与之相关的一处**尺度不真实**（已知限制，不影响结论）：真实 5 MeV α 对金核的最近接近距离约 45 fm，而金核半径只有 7.3 fm —— 粒子**根本碰不到核**，是在核外被推回来的。本页为了把核画得看得清（半径 12px）同时又把统计标定到"少数偏转、极少数反弹"，`b₉₀` 只有约 1.5px，于是轨迹在视觉上会"掠过核球"。想让它看起来"绕着核走"，就得把库仑常数放大十几倍并同步拉大核间距 —— 那样一屏只放得下两三列，"大量样本"又没了。这是二选一，本页选了统计。

> 📌 **一个容易被误解的物理点**：真实的 α 粒子（约 5 MeV）其实**碰不到**金核（金核库仑势垒约 20 MeV 以上），偏转 **100% 来自 1/r² 库仑斥力**。所谓"反弹"是被势垒推回，**不是几何碰撞**——所以旧版那道 21px 的"硬墙 + 镜面反射"和 16px 的力钳制都已被彻底移除。

> 🧠 **一个可以带进课堂的问题**：把原子按真实比例放大到足球场那么大，金核只有一粒米大小。那 α 粒子要想"正对"金核，概率有多低？——这就是"极少数被反弹"的由来。

#### 为什么调到 1 MeV 曾经"看着没偏"

有一段时间，把能量拉到 **1 MeV** 反而觉得"偏转现象不明显"，与"能量越低越容易被推开"的预期相反。查下来**物理没错，是画错了**：

| 量 | E = 1 MeV | E = 5 MeV | 说明 |
|---|---|---|---|
| 速度 | 2.5 px/帧 | 4.5 px/帧 | 能量只进速度，不进力 |
| 偏转（300 束 × 4 批 / 27 核） | **23.4%** | 16.3% | 低能确实更容易被推开 |
| 反弹 | **7.5%** | 1.5% | **正好 5 倍**（θ ∝ 1/E → `b₉₀` 大 5 倍 → 2D 截面概率线性大 5 倍） |
| ≥30° 的明显偏转 | **16.2%** | 4.7% | 3.4 倍 |
| 轨迹尾**曾经**的长度 | **99 px** | 179 px | ← 问题在这里 |

> 📌 上表是 **v7.2 当时（方形网阵列）** 的口径。v7.6 改成三角网后，面密度 ×1.155 且去掉了"列对齐"带来的沟道效应，同样 1200 样本下：**1 MeV → 偏转 46.6% / 反弹 21.9%；5 MeV → 偏转 16.9% / 反弹 4.1%**。定性结论不变，反弹的 1 MeV : 5 MeV 比值仍是约 **5.3 倍** —— 与 `b₉₀` 大 5 倍、2D 截面概率线性放大一致。

旧写法 `maxTrail = 帧数 × SUB`，**尾长按帧数算**：≥50 束进"密集模式"只留 40 帧，1 MeV 时 40 × 2.5 = **99 px**（画布宽 1200 px）。粒子在核处转弯后，弯的那一段几乎立刻被裁掉 —— 屏幕上只剩一小截近乎笔直的短尾，**看着就像没偏**。

现改为**按空间长度**留尾（密集 260 px / 稀疏 420 px / 极密 130 px），点数由 `尾长 ÷ (速度/4)` 反算，低速时自动多留点。实测 1 MeV 尾长 **99 → 206 px**、5 MeV **179 → 207 px**，两档等长；同时每帧采样从 8 点降到 4 点，**点数反而少了一半**（1 MeV 密集档 320 → 416 点，但覆盖的像素翻倍）。物理与统计**逐字节未变**。

> ⚠️ **老版本 `alpha_scattering_old.html` 的算法不能用**。它把 `1/E` 塞进库仑力分母（`force = kq₁q₂/(d²·min(E,5))`），E ≤ 5 时力与能量成反比。看着"1 MeV 特别明显"，其实是把能量**计算了两遍**（力里除一次、速度里再除一次）。用本页现在的 `K_COULOMB = 0.06` 复现这套算法，实测（300 束 × 4 批 / 27 核）：
>
> | 力倍率 | 1 MeV 直线 | 1 MeV **反弹** | 结论 |
> |---|---|---|---|
> | `(5/E)^0`（现版本） | 69.1% | **7.5%** | 与"极少数"相符 |
> | `(5/E)^0.25` | 57.2% | 16.9% | 六分之一被弹回，偏多 |
> | `(5/E)^0.5` | 42.2% | 33.2% | 三分之一被弹回，错 |
> | `(5/E)^1`（**老算法**） | 0.1% | **86.9%** | 几乎全被弹回，彻底违背实验结论 |
>
> 也就是说：为让低能档"更夸张"而恢复老算法，会把页面变成"1 MeV 时绝大多数 α 粒子被弹回来"，与卢瑟福"**极**少数"的结论正好相反。**偏转的强弱必须由 `θ ∝ 1/E` 自己给，不能靠改力**。

### ② α 散射页 · 布丁模型（对照用）

同一个页面里还能切到**汤姆逊的"葡萄干布丁"模型**，用来做**反证**。它与核式模型的差别只有一件事：**正电荷怎么分布**。

| 机制 | 核式模型 | 布丁模型 |
|---|---|---|
| **正电荷分布** | 集中在一个点核（`+79e`） | **均匀铺满整个原子球**（半径 R = nn/2 = **47.1px**，画成一个实心正电球，79 个电子嵌在里面） |
| **静电斥力** | `F ∝ 1/d²`，**不设下限**，`d → 0` 时持续增长 | **球外** `F ∝ 1/d²`；**球内** `F ∝ d/R³`（电荷量按 `d³/R³` 折算，故与 `d` 成正比） |
| **球心处受力** | 若能精确命中，`d → 0` 时理论发散（实践中被自适应子步吃到极小 `dt`） | **恰好为 0**（各方向抵消） |
| **力的峰值位置** | 在核心处（`d → 0`，无上界） | 在**球面** `d = R = 47.1px` 处取到峰值，峰值为 `kq₁q₂/R²`，且球内球外两式在 `d = R` 处**连续**（不会跳变） |
| **峰值大小** | 在 `d = 1px` 时约为球面处（`d = 47.1px`）的 **2200 倍** | 就停在球面那一档，**再往里只会更小**（球心处为零） |
| **能不能反弹** | 能 —— 只要 `b ≲ 0.4px`，单核就足以偏过 90° | **不能**：力的上限被 `kq₁q₂/R²` 钉死，且粒子进球后受力迅速回落 → 全程温和偏转。实测 900 束最大偏转仅 **5.9°** |
| **束数 / 能量 / 入射角 / 偏转判据** | —— | **完全不动**——切换只改"正电荷怎么分布"这一件事，是严格的对照实验 |

**实测对照**（300 束 × 3 批 = 900 个粒子 / 27 核 / 能量 5 MeV / 入射角 0°）：

| 原子模型 | 直线穿过 | 偏转 | 反弹 | 飞行全程最大偏转角 |
|---|---|---|---|---|
| **核式模型** | 700（77.8%） | 177（19.7%） | **23（2.6%）** | **167.8°** |
| **布丁模型** | **900（100%）** | **0** | **0** | 5.9° |

> 两张表里**没有一个字**是"布丁不许反弹"的开关：同一套 1/r² 公式、同一套 ≥90° / ≥10° 判据、同一批随机相位，只是正电荷的分布换了。布丁的"0"是**算出来的 0**。

> 布丁模型下**一束都不会被弹回来，甚至一束都不偏**。而教材明确写着"极少数 α 粒子被反弹回来"——**现象与模型矛盾 → 布丁模型错了**。这正是卢瑟福推翻它的逻辑，也是本节课最值得让学生自己撞见的一步。

> 🎨 **视觉呈现**：布丁球是**实线轮廓的正电球**（半径 50px，与核式模型的电子轨道圆同尺寸 → 两个模型的"原子"看起来一样大，差别只在里面装的是什么）+ 电子按**黄金角螺旋**（`Math.PI*(3−√5)`）均匀铺在球面上（`r = R·√((i+0.5)/n)`，面密度均匀）。**单球时**用径向渐变 + 79 个电子；**27 球时**改平色 + 每球 12 个点（27×79 = 2133 个圆点会糊成一片青雾，也拖帧），并在阵列右侧打一处「+79e 均匀分布」的标注，不在每个球里重复写 —— 否则 27 个标注会被 α 轨迹切碎。

### ③ 阴极射线页

| 机制 | 实现方式 |
|---|---|
| **几何** | 阴极 x=140 → 偏转区 x=560~940（长 380px）→ 荧光屏 x=1104。出射后还有 164px 的自由飞行段，射线是**折线**而不是简单抛物线 |
| **不加场** | 射线笔直打到屏心（实测 `y = 450`，即中轴） |
| **电场分支** | 极板间受**恒定横向力**，加速度 `a ∝ S`（S = 场强档位）→ 抛物线。屏上偏移量 `S_offset = A + (2A/L)·D`（A = 场区内横向位移、L = 380、D = 164），**反解** `A = −S / (1 + 2D/L)` 使屏上落点与场强档位线性对应 |
| **磁场分支** | 洛伦兹力 `qv × B` → **匀速圆周**运动，半径 `R = L / sin θ`（θ 为弦与入射方向的夹角，**上限 34°**）；出射后按切线直飞 → 屏上偏移 `S_offset = R(1 − cos θ) + tanθ·D` |
| **偏转上限** | 电场档位映射到 **0.35 ~ 1.0** 的偏转比例（**不是 0**）——最左档也保留约 81px 位移，拉到头不会像"程序坏了"。实测 1 / 6 / 10 档屏上偏移 **97 / 164 / 230px** |
| **播放状态** | `running` 标志：`false`（待机 / 暂停）时 `stepDeflect()` **直接落到目标值**、`stepFlow()` 不推进（画面整幅冻结）；`true` 时才走 `EASE = 0.12` 缓动与粒子流动。按钮文案与 `aria-pressed` 由 `syncRunButton()` 统一同步——探针据此断言"打开时确实没在播" |
| **电子束生长** | `flow` 表示束头已走过的路径比例，生长阶段电子 j 的位置 = `flow − j·SPACING`，所以**第 0 号电子永远在束头**、引导线画到它为止（`grow`）；`flow ≥ 1` 时置 `beamOn`，引导线锁定整条，电子改为**整条路径均匀铺满**并持续流动。`render()` 与 `stepFlow(dt)` 拆开，探针可手动步进后立即重绘读像素 |
| **切换动画** | 切换偏转方式时先把偏转量**收回 0**（`retracting = true`），再弯向新方向——不会从电场抛物线直接跳成磁场圆弧（**待机态下这一步被跳过**，直接落到新位置） |
| **正文字号** | **全站统一：正文 16px（小四）**，标题 17px，辅助小字 13~15px（v6.6 起，六页一致）。画布内标注 17px（CSS 显示约为画布的 0.87 倍 → 投影上约 15px）。字号改大后右栏由栏内滚动兜底，**页面总高只从 889 → 892px**，一屏不受影响 |
| **不撞极板 / 不出管** | 极板开口 302 ~ 598px、管壁 130 ~ 780px。实测最极端构图：电场入射最上点 `y = 327`、磁场入射最下点 `y = 566`、全程极值 `220 ~ 677`——**均在安全区内** |
| **两种偏转方向相反** | 电场 → 偏转 **163.56px**；磁场 → 偏转 **155.02px**，方向正好相反（`fieldsOpposite = true`，量值差仅 8.54px）——这就是"同一束电子被两种场分别拉向两侧"的互相印证 |

> 🧪 **为什么电场偏、磁场也偏，反而是好证据**：学生从电场知道"射线带负电、偏向正极板"；换成磁场后它偏向**相反**一侧——同一种粒子不可能一次带正电、一次带负电。结合方向就能推出"磁场对运动电荷的力垂直于速度与磁场平面"，从而确认这束东西是**带负电的粒子流**（汤姆逊把它命名为**电子**），原子**不是不可再分的**。

### ④ 场中的运动页（高中定量）· 与解析公式逐项对齐

这一页不用简化模型，而是**真物理量 + 速度 Verlet 数值积分**（kick–drift–kick，每步一次加速度求值），步长按"每步前进约 0.3px"取，磁场里再限制到周期的 1/3000。

| 机制 | 实现方式 |
|---|---|
| **加速段** | 阴极与双孔阳极之间施加恒定加速度 `a = qU₀/(m·L_acc)`（`L_acc` = 阴极到第二片阳极的距离），粒子从静止出发，越过第二片阳极时速率恰为 `v = √(2qU₀/m)` —— 与场强取自 `U₀/L_acc` 的匀强电场一致 |
| **偏转段（电场）** | 仅当粒子**位于极板区间内、且纵向偏离中轴小于半个板间距**时才加横向加速度 `a = qU/d`；一旦越出就判定"打在极板上"并终止 |
| **磁场段** | 洛伦兹力 `F = qv × B` 逐帧积分（**不是**"弦 + 切线"的简化圆弧）；纯磁场时场区是**半径 4 cm 的圆形有界区**，可在图中看到圆心 `O` 与轨道圆 `R` |
| **正交场（`U`、`B` 同加）** | 磁场区改成长方形、且**与极板同区间**：两个场作用在同一段区域上，`qE = qvB` 即净力为零 → 板内走直线；**出板即离场** → 屏上光斑回到正中（速度选择器）。若场区越过板出口只剩 `B`，配平后粒子会立刻被重新掰弯，屏上要偏出约 1 cm |
| **`tanθ` 的分母** | 取**沿板方向的分量 `v∥`**，不是合速度。用合速度会让 `tanθ` 系统性偏小约 1.9% |
| **屏距 `D`** | `X_SCREEN` 与"板出口→屏"距离由同一个 `state.dCm` 驱动，在每次刷新开头重算 —— 滑杆 / 预设 / 配平 / 重置四条入口都不会漏掉新屏距 |
| **配平的 `B` 不做量化** | 电子只需 `B = 0.3769 mT`；若按滑杆档位 0.05 mT 对齐，`q/m` 误差会从 **0.078% 恶化到 11%**。所以配平解保留全精度，滑杆位置只作视觉指示 |
| **积分步长兜底** | 手填很强的 `B` 时，按周期定的步长会让总步数爆表、轨迹断在半路 —— 按装置全长反推一个步长下限，宁可略降精度也不断线 |

**数值积分 vs 解析解**（电子 / `U₀ = 2000 V` / `U = 200 V` / `B = 5 mT`）：

| 量 | 解析式 | 解析值 | 数值积分 |
|---|---|---|---|
| 加速末速 `v` | `√(2qU₀/m)` | `2.652×10⁷ m/s` | 与解析一致 |
| 出板侧移 `y₁` | `UL²/(4dU₀)` | `0.703 cm` | `0.702 cm` |
| 偏转角 `tanθ` | `UL/(2dU₀)` | `0.1875` | `0.1872` |
| 反向延长线落点 | 极板中点 | `510 px` | `512.7 px` |
| 轨道半径 `R` | `mv/(qB)` | `3.02 cm` | 与解析一致 |
| 回旋周期 `T` | `2πm/(qB)` | `7.145 ns` | **与速率无关**（换 `U₀` 后 `T` 不变） |
| 配平后的 `q/m` | `E²/(2U₀B²)` | `1.76×10¹¹ C/kg` | 误差 **0.078%**，屏上偏移 `0 cm` |

> 📐 **一页能讲完的高中考点**：类平抛的两个方向独立性、反向延长过极板中点、`T` 与速率无关、`R = mv/(qB)`、速度选择器 `v = E/B`、汤姆逊测荷质比 `q/m = E²/(2U₀B²)`，以及"换粒子后 `y₁`、`tanθ` 不变、符号相反"这个经典结论。

### ⑤ 玻尔三维页 · 三维投影与能级跃迁

**三维是怎么算的**（全部手写，无任何 3D 库）：

| 环节 | 做法 |
|---|---|
| **轨道平面** | 第 `n` 层取倾角 `θ = 0.40 + 0.55n`、方位角 `φ = 0.85n + 0.35`，由法向量 `N` 与参考向量叉乘得到平面内的一组正交基 `u`、`v`；轨道上的点 = `r·(cosα·u + sinα·v)`。**各层 `θ`、`φ` 都不同 → 平面两两不平行** |
| **相机** | 先绕 Y 轴偏航（拖动横向）、再绕 X 轴俯仰（拖动纵向），俯仰钳在 ±1.25 rad 防止翻转 |
| **投影** | 透视 `s = F / (F + z)`，`F = 1500`；屏幕坐标 = `中心 + 相机坐标 × s` |
| **深度** | 把每段轨道线、每个电子、原子核都放进一个列表，按 `z` 从大到小排序后依次绘制（画家算法）。`z` 越大越远 → 线更细、更暗、电子更小，近处的亮而粗 |
| **原子核** | 半径 `10 + 1.8·∛A`（`A` = 质量数），径向渐变球 + `+Ze` 标注；核排在 `z = 0`，所以**远侧的电子会被核挡住、近侧的电子会挡住核** —— 遮挡关系是算出来的，不是画上去的 |

**跃迁与光谱的算法**：

| 量 | 公式 / 取值 |
|---|---|
| 能级 | `Eₙ = −13.6/n² eV`（n = 1~6，氢） |
| 跃迁能量 | `ΔE = 13.6 × (1/n低² − 1/n高²)` |
| 波长 | `λ = hc/ΔE`，取 `hc = 1240 eV·nm` |
| 巴耳末系 | 3→2 `656.3`（页面算 656.5）· 4→2 `486.1`（486.3）· 5→2 `434.0`（434.2）· 6→2 `410.2`（410.3）nm —— **四条全在 400~700 nm 可见区内** |
| 莱曼 / 帕邢 | 2→1 `121.6` nm（紫外）· 4→3 `1875` nm（红外）—— 肉眼看不见，光谱条上落在压暗区 |
| 动画 | `激发（0.75s 螺旋升到高能级）→ 停留（0.35s）→ 跃迁（0.75s 落到低能级）→ 放光子（1.15s 正弦波形飞出）`，落定后**电子停在落点那一层**（不会弹回 n=1），光谱上对应那条线保持点亮 |

> 📎 **和课本的对应**：这一页把"**定态轨道分立 → 发光分立**"这条因果链做成了可看的过程 —— 学生看到的是"电子掉下来 → 飞出一个光子 → 某条亮线亮起"，而不是先被告知"氢光谱有四条线"。

## 📐 三维投影是怎么实现的（`bohr_model_3d.html`）

**为什么不引入 three.js**：本项目所有页面都挂着「零依赖、离线可用、单文件」这条硬约束。三维页要画的东西其实只有三类 —— **线（轨道）、点（电子）、一个球（原子核）**，用不到光照、材质、贴图。所以只取三维数学，光栅化仍交给 Canvas 2D：

```js
// 世界 → 相机：先绕 Y 偏航，再绕 X 俯仰
function toCam(p) {
  const x1 =  p.x*cos(yaw) + p.z*sin(yaw);
  const z1 = -p.x*sin(yaw) + p.z*cos(yaw);
  return { x: x1, y: p.y*cos(pitch) - z1*sin(pitch), z: p.y*sin(pitch) + z1*cos(pitch) };
}
// 相机 → 屏幕：透视。z 越大越远 → 缩放越小
function project(p) {
  const c = toCam(p), s = FOCAL / (FOCAL + c.z);
  return { x: CX + c.x*s, y: CY + c.y*s, s, z: c.z };
}
```

**深度排序用画家算法**：每帧把所有可绘制物（每段轨道线 / 每个电子 / 原子核 / 光子）塞进一个数组，按 `z` 从大到小排一遍再画。远侧的电子因此会被原子核挡住，近侧的电子会挡住核 —— **遮挡关系是算出来的**。实测每帧约 700 个绘制项，`electron_in_field.html` 的数值积分同量级，60fps 无压力。

**踩过的两个坑**：

1. `r ∝ n²`（真实玻尔标度）会让 n=1 半径只有 20px（比原子核还小）、n=6 直接冲出画布 → 改成 `n^1.5` 并在页面里注明；
2. 跃迁结束后若只改"读数"不改"电子画在哪一层"，会出现**读数说 3→2、画面里电子却弹回 n=1** 的自相矛盾 → 加了 `applyHydrogenLevel()`，落定后把被占据的层真正搬到落点（探针专门断言这一条）。

## 🎓 教学设计

本项目的材料可以串成**三条完整的证据链**——第一条回答"原子能不能再分"，第二条回答"原子里面长什么样"，第三条（高中拓展）回答"这束粒子到底有多重、带多少电"：

**证据链一 · 阴极射线（1897）**

```
射线在电场中偏向正极板  →  射线带负电
换成磁场后偏向相反一侧  →  同一种粒子不可能一次带正电一次带负电
                        →  它是一束带负电的粒子流  →  命名"电子"
                        →  原子不是不可再分的  →  葡萄干布丁模型
```

**证据链二 · α 粒子散射（1911）**

```
大多数直线穿过  →  原子内部十分空旷
少数发生偏转    →  原子核带正电
极少数被反弹    →  原子核体积小、质量大
                →  核式结构模型（布丁模型被推翻）
```

**证据链三 · 定量测荷质比（高中物理拓展）**

```
电场中偏转量 y₁、tanθ      →  可算出"偏转到底有多厉害"
换成磁场看圆周 R、T        →  T 与速率无关（回旋加速器的基础）
两场同区间调到净力为零      →  v = E/B（速度选择器）
结合 ½mv² = qU₀             →  q/m = E²/(2U₀B²)  →  电子荷质比
```

**把前两条化学史链链接起来**：在 α 散射页把「原子模型」切到**布丁模型**、再发射一次——**一束都不偏、更不反弹**，与实验现象矛盾，学生自己就能得出"布丁模型站不住"的结论。这是本项目最核心的一步设计。

**高中延长线**：把阴极射线页的现象带进 `electron_in_field.html`——同一套装置加上真实电压与磁场，让学生把"看得见的现象"算成"可读出的数字"，最后点一次「汤姆逊配平」反推 `q/m`，回到 1897 年汤姆逊做过的那件事。

**适用学段**：初中（原子的结构、科学探究）→ 高中（原子结构、α 粒子散射实验、核式模型、带电粒子在电场 / 磁场中的运动）。同一套材料，初中用到"现象 + 结论"，高中可再追问"为什么偏转角有大有小""能量对偏转有什么影响""为什么电场与磁场的偏转方向相反"，以及定量页里的 `y₁`、`tanθ`、`R`、`T`、`q/m`。

> 📎 45 分钟教学简案（以初中"原子的结构"一课为样例，含操作流程、提问设计、分层作业与评价量规）**暂未随仓库提供**，定稿后再补；上面三条证据链与六个页面本身已可直接用于备课。

## 🛠️ 技术栈

- **纯前端**：HTML + CSS + 原生 JavaScript，**零依赖、零构建**（无 CDN、无字体外链、无脚本引用、无图片资源——六页外部引用实测 **0 处**）。三维页的旋转矩阵、透视投影、深度排序全部手写，**未引入 three.js / WebGL**
- **渲染**：HTML5 Canvas 2D（阴极射线 1200×900 / 场中运动 1200×900 / α 散射 1200×900 / 玻尔二维 1000×750）；`index.html` 为纯 HTML + CSS，**不含任何 JavaScript**
- **动画**：`requestAnimationFrame` 驱动（按帧时间差 `dt` 推进，切标签页回来不会跳帧），偏转量用**指数缓动**（`EASE = 0.12`）过渡；阴极射线页有 `running` **待机标志**与 `flow` **束流进度**——打开页面是一张空装置图，点「▶ 开始实验」第一个电子射出、引导线随它长出（配合"先讲解、后实验"的课堂动线）
- **数值积分**：场中运动页用**速度 Verlet**（kick–drift–kick）逐帧求解 `F = qE + qv × B`，与解析公式逐项对齐（误差 < 0.2%）
- **辉光效果**：不用 `shadowBlur`（在大画布上开销高），改为**三层描边叠加**（11px / 10% → 5px / 32% → 2px / 95%）冒充光晕，300 束齐射仍流畅
- **兼容性**：三个调用 `ctx.roundRect` 的画布页（阴极射线 / 场中运动 / α 散射）**内置 20 行 polyfill** 兜住旧内核（Chrome/Edge < 99）——原生支持时整段跳过，行为零变化。要求 **Chrome / Edge ≥ 99**（或 Firefox ≥ 112、Safari ≥ 16.4），详见「快速开始」
- **跨平台**：Windows / macOS / Linux / 平板均可运行，**支持完全离线使用**
- **无后端**：纯静态文件，可直接托管到 GitHub Pages

- **三维页的轨道半径与转速是压缩过的**：半径按 `n^1.5`（真实玻尔模型为 `n²`）、转速按 `1/n^1.5`（真实为 `1/n³`）。真实 `n²` 会让 n=1 小到看不见、n=6 大到出画布；真实 `1/n³` 会让外层电子几乎静止、看不出"分层运动"。**页面内已把这句注明**，讲课时建议顺带点一句"这是为了看清楚而压过的比例"。
- **三维页的跃迁只对氢开放**：玻尔的 `Eₙ = −13.6/n² eV` 只对氢及类氢离子严格成立，多电子原子因电子间屏蔽并不适用。切到其它元素时跃迁按钮禁用、能级图加遮罩说明，**不编造多电子原子的能级**。
- **三维页的轨道平面取向是示意**：各层倾角/方位角按固定公式错开，只为让学生看出"不在同一平面上"，不代表真实的轨道空间取向（那属于量子力学的原子轨道概念，超出中学范围）。
- **阴极射线页的磁场是"简化圆弧"**：只取圆周运动的**弦 + 切线出射**这一几何结果，没有逐帧积分 `qv × B`；偏转角上限锁在 **34°**，避免小半径圆弧冲出管壁。给学生讲"磁场让电子走圆弧"足够，但不适合做定量的半径测算 —— **要做定量请用 `electron_in_field.html`**（那一页是真积分，`R`、`T` 都能与解析式对上）。
- **场中运动页的几处理想化**：极板之间按**均匀电场**处理、磁场区边界是**理想陡壁**（一出圆/矩形立刻不受力，没有边缘场效应）；忽略重力与粒子间相互作用；按**非相对论**公式计算 —— 页面上限 `U₀ = 20000 V` 对应 `v/c ≈ 0.28`，若真要填到那么高，`v = √(2qU₀/m)` 会有可观偏差，课堂建议留在 `U₀ ≲ 5000 V` 区间。
- **布丁模型是"反证用的近似"**：`+79e` 按均匀球体处理（真实汤姆逊模型里电子也在里面、还会有相互屏蔽），目的是让"力被摊薄 → 一束都弹不回来"这个**定性结论**成立，不追求定量。
- **过渡元素的电子排布**：21~36 号的 M 层电子数会 >8（如 Fe = 2, 8, 14, 2），与"最外层不超过 8 个"的直觉不同——这是真实的 3d 填充；初中课上可先带过，高中正好拿它讲能级交错。提问前建议先备好说法。
- **物理模型为教学简化**：α 粒子与核的作用按纯 1/r² 斥力叠加（无钳制、近核靠自适应子步保精度），数值不追求与真实实验一致；但"直线 / 偏转 / 反弹"三者的**相对比例**是同一套判据算出来的，不是按预期摆好的。
