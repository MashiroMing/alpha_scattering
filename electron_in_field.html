🧲 带电粒子在场中的运动 · 定量探究

从阴极射线到示波管：加速 → 电偏转（类平抛）→ 磁偏转（圆周）→ 正交场测荷质比
电荷量 q 单位：元电荷 e（负号表示带负电）
质量 m 单位：原子质量单位 u（质子 ≈ 1）
滑杆粗调，右侧数字框可手填任意精度：D 越大，同样的偏转角被放得越开（Y = y₁ + D·tanθ）
观察到的现象
① 电场加速（阴极 → 阳极）
进入偏转区的速率 vv = √(2qU₀/m)
—
加速历时 t₀L_acc = v·t₀/2
—
② 电场偏转：类平抛运动
板间场强 EE = U/d，d = 2.00 cm
—
横向加速度 aa = qE/m
—
穿越极板用时 t₁t₁ = L/v，L = 7.50 cm
—
出板时侧移 y₁y₁ = ½at₁² = UL²/(4dU₀)
—
偏转角正切 tanθtanθ = v⊥/v = UL/(2dU₀)
—
板出口 → 荧光屏距离 D右栏滑杆可调 2.0 – 12.5 cm
—
荧光屏上总偏移 YY = y₁ + D·tanθ
—
③ 磁场偏转：匀速圆周运动
轨道半径 RR = mv/(qB)
—
回旋周期 TT = 2πm/(qB)
—
在场区内转过的圆心角 φsinφ = 弦长/(2R)
—
出射偏向角 ββ = 圆心角 φ（偏向角等于圆心角）
—
④ 正交电磁场 · 汤姆逊测荷质比
速度选择器条件v = E/B
—
测量值 |q|/mq/m = v²/(2U₀) = E²/(2U₀B²)
—
理论值 |q|/m由粒子自身的 q、m 算出
—
把 U 调到非零、再点「汤姆逊配平」，让电场偏转与磁场偏转正好抵消，即可反推出 q/m。
💡 怎么用 / 公式速查
  • 这是一套串起来的装置：左边阴极—阳极用 U₀ 把粒子从静止加速；中间平行板加 U 让它类平抛；右边圆形有界磁场加 B 让它转圆弧；最后打在荧光屏上。
  • 比例尺：画面 1 cm = 40 px。极板长 L = 7.50 cm、间距 d = 2.00 cm、磁场区半径 4.00 cm（正交场工况下改为与极板同宽同区间的矩形）、屏距 D 由滑杆调节（2.0 – 12.5 cm，默认 11.5 cm）——全部是真实尺寸，面板里的数字可直接拿去做题。
  • 参数可以手填：每个滑杆右边都有数字框，支持任意精度——比如汤姆逊配平要用的 B = 0.3769 mT，或 U₀ = 1837.5 V。填的值超出滑杆量程也没关系（滑杆会自动扩量程容纳），只有屏距 D 受画布限制夹在 0.5 – 12.8 cm。按 Enter 或点开别处即生效。
  • 拖 D 滑杆能看什么：荧光屏会真的在装置上左右移动，屏上那根黄色尺寸线就是偏移量的读数。Y = y₁ + D·tanθ —— y₁ 与 tanθ 都不随 D 变，所以 Y 对 D 是一次函数：屏幕拉远，同样的偏转角被"杠杆"放得更大，这正是示波管要长脖子的原因。
  • 三条主线（对应三种工况）：
    ① 只加 U：抛物线，y₁ = UL²/(4dU₀)、tanθ = UL/(2dU₀)；
    ② 只加 B：圆弧，R = mv/(qB)、T = 2πm/(qB)；
    ③ 同时加 U 和 B：正交场，v = E/B 时不偏转。
  • 必考几何结论：出射速度方向反向延长，必过极板中点（图中那条虚线）。这条线一画，Y = y₁ + D·tanθ 里的 D 该从哪量起就再也不会错。
  • 换粒子看差异：换成质子 / α 粒子，y₁、tanθ 竟然完全不变（公式里 q、m 被 U₀ 抵消了）——但磁场里的 R、T 差了几千倍，B 的量程也会自动跟着换。
  • 汤姆逊配平：先给一个非零的 U，点按钮自动扫出使净偏转为零的 B，此时 qE = qvB，代入 ½mv² = qU₀ 就得 q/m = E²/(2U₀B²)——这正是 1897 年汤姆逊测电子荷质比的思路，也是"阴极射线"这一页的源头。注意正交场工况下磁场区被裁成与极板同宽：两个场作用在同一段区域，粒子一出板就再无场力，所以配平后是沿中轴直线飞到屏正中（教科书里速度选择器的样子），不会"出了板又被磁场拐一下"。
  • 推荐课堂动线：① 只加 U → 讲类平抛怎么"拆成两个方向"来算，再勾上「反向延长线」坐实那条几何结论；② 撤掉 U 换成 B → 讲圆心怎么找、T 与速率无关；③ U、B 同时加 → 配平，反推 q/m。
